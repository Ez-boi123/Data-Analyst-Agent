# Schema 结构质量评估

评分范围是当前加载的数据源，覆盖全部已加载表，并非本次问题的表选择准确率，也不是答案正确概率。不调用 LLM；规则版本以代码为准。

- 单表评分：80% × 字段平均非空率 + 20% × 有非空样例的字段占比。
- 关联评分：字段类型兼容时，50% × 候选子表去重键覆盖率 + 30% × 较高侧键唯一率 + 20% × 较低侧键非空率；类型不兼容则为 0。
- 唯一率 = 非空唯一值数 / 非空行数。唯一率较高的一侧作为候选父表；相等时按候选关联右侧处理。这是结构启发式，不是已验证外键。
- 单表数据源直接使用表评分。多表总分 = 60% × 表评分均值 + 40% × 关联评分均值 × 可连通表对占比。空表在均值中按 0 计入；全部为空时返回未评估。
- 关联评分使用已加载列的全部去重值。候选发现仍限于同名标识字段、前 50,000 个唯一值重合度至少 5%，最多 20 条候选。因此无候选会扣分，但不证明数据无法关联。

接口在 Schema 证据中返回 assessment（score、method、components、warnings、scope），表和关联也各自返回 assessment。前端将 0–1 分值展示为 0%–100%（规则评估，非正确概率），并展示评分公式和风险说明。

高分只能说明这些结构检查通过。业务字段含义、问题匹配、聚合口径和 SQL 正确性均未验证。小样本也可能获得高结构分；评分仅适用于已加载快照，不保证外部数据库最新状态。
