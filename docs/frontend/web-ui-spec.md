# Data Analyst Agent Web UI 技术规范

## 1. 产品定位

Data Analyst Agent Web UI 是面向业务负责人的智能数据分析工作台，聚焦多业务、多表场景下的数据理解、表关联推理、SQL 生成、错误自修复和洞察沉淀。

v1 的核心产物是“分析任务”，而不是一次性聊天消息。每个任务沉淀用户问题、业务口径、Schema 证据、Join 路径、SQL、执行与修复记录、结果预览、图表洞察、评论和追问分支。

## 2. 页面范围

v1 包含：

- 分析任务首页
- 分析工作台
- 可分享任务页
- 数据源 / Schema 轻量管理
- 业务词典 / 指标口径
- 基础设置
- 内置“经营指标异动分析”样例任务

v1 不包含：

- 完整 BI 拖拽编辑器
- 可编辑数据建模器
- 多人实时协同编辑
- 完整数据治理平台
- 移动端复杂 SQL / Schema 编辑

## 3. 技术栈

- Next.js + React + TypeScript，使用 App Router
- Tailwind CSS 作为样式基础
- React Flow 用于 Schema 关系和 Join 路径解释图
- TanStack Table 用于 SQL 结果表预览、分页和列控制
- Apache ECharts 用于趋势、对比、贡献度等图表
- Zustand 用于工作台内轻量客户端状态
- next-intl 支持中英双语

## 4. 路由

- `/`：分析任务首页，支持直接输入提示词创建任务
- `/tasks/[taskId]`：分析工作台
- `/share/tasks/[taskId]`：可分享任务页
- `/data-sources`：数据源与 Schema 状态
- `/glossary`：业务词典与指标口径
- `/settings`：语言、权限视图、偏好设置

## 5. 核心体验

分析任务首页采用居中启动台设计：上方产品标题，中间长胶囊输入框，下方历史任务。用户直接输入分析问题并创建任务，不再单独进入新建任务页。

分析工作台采用左侧 Agent 对话栏 + 右侧结构化分析区。左侧对话栏支持展开和收起，展开时纵向铺满页面，顶部为 Agent 对话状态，中间为消息区，底部为追问输入框和模型选择。右侧展示固定任务标题、任务摘要、证据时间线、阶段详情、SQL、结果表、图表和审计信息。

## 6. 分析阶段

分析阶段包括：

- `clarifying`：澄清业务域、时间范围、指标口径、筛选条件
- `understanding`：理解问题与生成分析计划
- `schema_retrieval`：检索相关表、字段、指标
- `relation_reasoning`：推理 Join 路径与过滤条件
- `sql_generation`：生成 SQL
- `sql_execution`：只读沙箱执行
- `sql_repairing`：错误自修复
- `insight_generation`：生成图表、结论、证据和建议
- `completed`：完成，可分享、评论、追问
- `failed_recoverable`：可恢复失败，允许补充信息或重试

## 7. 证据展示

默认展示：

- 业务问题理解
- 指标口径与假设
- 数据源、业务域和权限范围
- 相关表及选择原因
- Join 路径、主外键或推断关系、置信度
- 时间范围、过滤条件、分组维度
- 关键结论的数据证据

不展示原始模型思维链，只展示证据化解释。

## 8. SQL 与结果

- SQL 默认折叠或结构化展示。
- SQL 展示支持语法高亮。
- SQL 报错时展示错误摘要、修复动作、SQL Diff、重试历史和耗时。
- 结果表默认展示预览数据，不一次性加载大结果集。
- 结果表必须显示行数限制、字段类型、分页、列显示控制和导出入口。

## 9. 安全、权限与审计

- UI 明确显示只读沙箱状态。
- 只允许 SELECT 类只读查询。
- 默认展示限行、超时、脱敏、权限过滤状态。
- 敏感字段在 Schema 图和结果表中必须标识或脱敏。
- v1 使用业务域权限模型。
- 分享页只允许有权限用户访问。
- 任务级审计记录发起人、数据域、生成与执行 SQL、修复次数、分享和追问。

## 10. 验收标准

必须支持完整演示链路：

- 用户在首页输入经营指标异动问题。
- Agent 澄清关键条件。
- 工作台展示阶段状态机。
- Schema 图展示相关表和 Join 路径。
- SQL 生成后展示高亮代码。
- 模拟一次 SQL 报错并展示修复摘要、SQL Diff 和重试成功。
- 结果表分页预览。
- 图表展示 GMV 趋势和维度拆解。
- 洞察区输出结论、证据和建议。
- 任务完成后可分享、评论、追问并生成分析分支。
